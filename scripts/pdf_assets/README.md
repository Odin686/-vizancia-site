# Vizancia classroom print template

The Inter Regular and Bold fonts are bundled under the SIL Open Font License;
see inter/LICENSE.txt. Layout primitives live in build-evidence-to-action.py.
Use the existing navy, purple and teal palette, Letter pages, 46-point side
margins, measured paragraphs, stable page codes, and restrained rules/callouts.
Body text is 10.5-11pt; most tables use 9.5-10pt. Do not shrink text to hide
layout overflow. A source text change must be followed by a complete rebuild
and visual inspection of every rendered page.

The PDFs have embedded fonts, searchable text, language metadata, bookmarks and
source links. They are not tagged PDF/UA documents; agree an accessible reading
or response alternative when needed. Learner responses are paper-based, not
fillable PDF fields. No learner information or telemetry is embedded.
